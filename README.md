## Percentage splits

Turn on **Split by percentage** on an item to share its cost unevenly. Two people use one slider; larger groups get a percentage box and slider for each person. Values can have up to two decimal places and must add up to 100% before you can tap **Done**.

The controls show the current euro amount beside each person, using the item price and their percentage. The amounts are hidden while the total is incomplete so they cannot be mistaken for final charges.

This browser remembers each item's switch and percentages by item name for future receipts. Turning the switch off keeps the percentages for later. Choosing a person or Common switches the item back to an ordinary assignment.

Run the calculation and receipt tests with `npm test`.
